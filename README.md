# 單字卡 WordCards

## 專案簡介

本專案是一個使用 **C# Windows Forms** 製作的英文單字卡練習程式，主要功能是讓使用者可以瀏覽英文單字、查看音標與中文解釋，並播放對應的單字音檔，輔助英文背誦與複習。

程式讀取文字檔中的單字資料後，會將所有單字顯示在左側清單，使用者點選單字即可在右側顯示詳細內容，也可以按下播放按鈕聆聽發音。專案另外加入了搜尋、夜間模式、測驗模式、學習統計、播放速度調整與編輯單字等功能，使單字練習更方便。

---

## 專案功能

### 1. 單字瀏覽

- 左側顯示完整單字清單。
- 點選單字後，右側會顯示英文單字、音標與中文解釋。
- 清單使用斑馬紋顯示，提高閱讀性。
- 支援搜尋關鍵字高亮顯示。

### 2. 發音播放

- 每個單字可設定對應音檔路徑。
- 點選單字或按下播放按鈕時，可播放該單字音檔。
- 支援常見音效格式，例如 `.mp3`、`.wav`、`.wma`。

### 3. 自動播放

- 按下 **Play** 後會自動依序播放單字。
- 再次按下可停止播放。
- 可透過下方播放速度滑桿調整自動播放間隔。

### 4. 鍵盤快捷鍵

| 按鍵 | 功能 |
|---|---|
| Enter | 下一個單字 |
| Space | 重複播放目前單字 |
| Q | 測驗模式中顯示答案 |
| ↑ | 測驗模式中標記答對 |
| ↓ | 測驗模式中標記答錯 |
| + | 放大單字字體 |
| - | 縮小單字字體 |

### 5. 測驗模式

- 啟用測驗模式後，中文解釋會先被隱藏。
- 使用者可以先看英文單字與音標，自己回想中文意思。
- 按下 `Q` 可顯示答案。
- 按 `↑` 記錄答對，按 `↓` 記錄答錯。

### 6. 學習統計

統計功能會記錄：

- 單字總數
- 答對次數
- 答錯次數
- 答對率
- 學習時間

### 7. 夜間模式

- 可切換白天 / 夜間模式。
- 夜間模式會調整背景與文字顏色，降低長時間使用時的視覺疲勞。

### 8. 單字編輯

雙擊左側清單中的單字後，會開啟單字編輯視窗，可修改：

- 音標
- 音檔路徑
- 中文解釋

單字本身為唯讀，避免不小心修改原始單字。

建議使用以下環境執行：

- 開發工具：Visual Studio 2019 或 Visual Studio 2022
- 專案類型：Windows Forms App

## 執行說明

### 方法一：使用 Visual Studio 執行

1. 開啟 Visual Studio。
2. 開啟本專案的 `.sln` 解決方案檔。
3. 確認 `WordCards.txt` 與音檔資料夾存在於執行目錄。
4. 按下上方的 **Start** 或快捷鍵 `F5` 執行程式。
5. 程式啟動後即可開始使用單字卡功能。

### 方法二：直接執行 exe

1. 先使用 Visual Studio 建置專案。
2. 到輸出資料夾中找到執行檔，例如：

```text
bin\Debug\
```

或

```text
bin\Release\
```

3. 確認同一層資料夾中有：

```text
WordCards.txt
Sound\
```

4. 雙擊 `.exe` 執行程式。

## 單字資料格式

`WordCards.txt` 為程式讀取單字資料的主要來源。每一筆單字資料通常包含：

- 英文單字
- 音標
- 音檔路徑
- 中文解釋

實際格式需依照 `WordCollection` 與 `WordItem` 類別中的讀取規則設定。

範例概念如下：

```text
abacus
` æbəkəs
Sound\A\abacus.mp3
<aba-=abax-:一種計算工具> + <-us: calculus 小圓石>
```

## 操作流程

1. 啟動程式。
2. 左側單字清單會載入 `WordCards.txt` 中的單字。
3. 點選任一單字後，右側會顯示該單字的詳細資訊。
4. 按下 **Play** 可播放單字發音。
5. 可使用搜尋框快速尋找單字。
6. 可切換夜間模式或測驗模式。
7. 雙擊單字可開啟編輯視窗修改資料。
8. 修改後按下儲存，程式會將更新後的資料寫回單字檔。

## 注意事項

- 若音檔路徑錯誤，程式會顯示找不到音效檔。
- 若 `WordCards.txt` 不存在，程式會跳出錯誤訊息並結束。
- 若要讓音檔能正常播放，請確認音檔位置與 `WordCards.txt` 中記錄的路徑一致。
- 建議將音檔放在專案的 `Sound` 資料夾中，方便管理。
